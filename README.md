# GraphRAG Demo

An implementation of the **GraphRAG** pattern (entity/relation extraction →
knowledge graph → community detection → community summarization → global +
local retrieval → answer synthesis via Azure OpenAI), demonstrated on a
synthetic test dataset ("The Solace Initiative" — a corporate-espionage/
climate-tech story with people, organizations, locations and events).

## How it works

```
data/documents/*.txt
        │
        ▼
src/extraction.py     regex + capitalization heuristics -- OR -- Azure OpenAI LLM extraction
                       (selectable) -> entities & relations
        │
        ▼
src/graph_builder.py  builds a networkx graph, runs Louvain community detection
        │
        ▼
src/summarizer.py     summarizes each community via Azure OpenAI
        │
        ▼
src/embeddings.py     TF-IDF -- OR -- Azure OpenAI embeddings (selectable) retrieval indexes
                       over communities / entities / sentences
        │
        ▼
src/query_engine.py   global search (communities) + local search (entities/graph)
                       + sentence retrieval → answer synthesis via Azure OpenAI
        │
        ▼
src/app.py (Streamlit UI)   /   src/cli.py (command line)
```

### Assumptions made for this demo

- **Azure OpenAI is required.** There is no offline/extractive fallback --
  community summaries and answers are always generated by calling your Azure
  OpenAI deployment. Copy `.env.example` to `.env` and set
  `AZURE_OPENAI_ENDPOINT`, `OPENAI_API_KEY` (your Azure key), and
  `AZURE_OPENAI_DEPLOYMENT` (the deployment name from Azure AI Foundry /
  Azure Portal → your resource → Deployments).
- **No spaCy/torch/transformers required.** Retrieval has two selectable
  methods: offline TF-IDF (scikit-learn, the default) or real semantic search
  via Azure OpenAI embeddings (`AZURE_OPENAI_EMBEDDING_DEPLOYMENT`, e.g.
  `text-embedding-3-small`). Entity extraction also has two selectable
  methods: fast offline capitalization/suffix heuristics (`regex`, the
  default), or Azure OpenAI-based extraction (`llm`), which calls your
  deployment once per document to identify entities and relations as
  structured JSON. Choose between them in the Streamlit sidebar, or via
  `--extract regex|llm` / `--retrieval tfidf|azure_embedding` on the CLI.
- **Test data is synthetic**, written specifically so the resulting graph has
  clear entities (people/orgs/places/events) and multiple communities
  (a corporate faction, a whistleblower/research faction, and a
  regulatory/press faction) to showcase GraphRAG's community-based retrieval.

## Setup

```powershell
# from the project root
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
# edit .env: set AZURE_OPENAI_ENDPOINT, OPENAI_API_KEY, AZURE_OPENAI_DEPLOYMENT
```

## Run

**Command line:**

```powershell
.venv\Scripts\python -m src.cli --stats
.venv\Scripts\python -m src.cli "Who leaked the Project Chimera documents?"
.venv\Scripts\python -m src.cli --extract llm "Who leaked the Project Chimera documents?"
.venv\Scripts\python -m src.cli --retrieval azure_embedding "Who leaked the Project Chimera documents?"
```

**Web UI (recommended):**

```powershell
.venv\Scripts\streamlit run src\app.py
```

This opens a browser UI with:
- **Extraction method** (sidebar) -- choose `Regex (heuristic)` or
  `LLM (Azure OpenAI)` before/while the index is built.
- **Retrieval method** (sidebar) -- choose `TF-IDF` or
  `Azure OpenAI embeddings` for community/entity/sentence retrieval.
- **Ask a question** — type a question, see the generated answer plus the
  full evidence trail (which communities/entities/sentences were used).
- **Explore graph** — interactive graph visualization, colored by community
  or entity type.
- **Communities** — the summaries generated for each detected community.

The sidebar has a **Test LLM connection** button to verify your Azure OpenAI
setup independently of the rest of the app.

## Project structure

```
data/documents/       synthetic test corpus (8 short articles)
src/extraction.py      entity + relation extraction
src/graph_builder.py   graph construction + community detection
src/summarizer.py      community summarization
src/embeddings.py      TF-IDF retrieval indexes
src/pipeline.py        orchestrates the full build
src/query_engine.py    global/local search + answer synthesis
src/llm.py             optional OpenAI integration
src/cli.py             command-line entry point
src/app.py             Streamlit UI
```
